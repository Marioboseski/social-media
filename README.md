# Social Media App (Instagram-like)

A modern social media web application inspired by instagram.
The project focuses on clean architecture, reusable components, clean UI/UX, responsive design. 

# Features 

* Responsive layout (mobile-first)

* Save/Unsave posts

* Stories preview

* Like/Unlike posts

* Clean and scalable folder structure 

* Reusable code 

* Form validation (password rules, email...)

* multiple pages (Feed, exlore, messages, saved posts, profile)
